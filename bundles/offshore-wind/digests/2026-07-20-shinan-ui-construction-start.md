# Construction Starts on 390 MW Shinan Ui Offshore Wind Project

[Hanwha Ocean](/companies/hanwha-ocean.md) has started construction of the
390 MW [Shinan Ui offshore wind project](/projects/shinan-ui.md) off Shinan
County (Jeollanam-do), South Korea, marking another milestone in the
country's growing offshore wind pipeline.
