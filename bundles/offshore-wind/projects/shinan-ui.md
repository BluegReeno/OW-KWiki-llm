# Shinan Ui Offshore Wind Project

The Shinan Ui Offshore Wind Project is a 390 MW offshore wind farm off
Shinan County in South Korea's Jeollanam-do region. It is developed by
[Hanwha Ocean](/companies/hanwha-ocean.md), which began construction of the
project in July 2026.

The start of construction adds to a wave of South Korean offshore wind
activity, alongside the 3.2 GW [Jindo cluster](/projects/jindo.md) and
capacity awarded in the country's 2026 offshore wind auction.
